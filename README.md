# Dream Ledger – Premium Real Estate Portal

> A modern, premium **Real Estate Portal** built using **HTML5, CSS3, and Vanilla JavaScript**, featuring a luxurious UI, advanced property search, favorites, owner contact, and a complete **Admin CMS** powered by **LocalStorage**. The project includes a premium landing page and a standalone admin dashboard.
